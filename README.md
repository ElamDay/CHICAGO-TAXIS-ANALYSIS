# Chicago Taxi Analysis

Proyecto de análisis de datos enfocado en el mercado de taxis de Chicago y en la relación entre las condiciones meteorológicas y la duración de los viajes.

## Objetivo

El objetivo del proyecto es analizar la actividad de las compañías de taxi, identificar las zonas con mayor número promedio de viajes y comprobar si la duración promedio de los viajes entre Loop y el Aeropuerto Internacional O'Hare cambia según las condiciones meteorológicas.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- SciPy
- Jupyter Notebook
- SQL

## Contenido del análisis

El proyecto incluye:

- Revisión y limpieza de datos
- Análisis de compañías de taxi
- Análisis de barrios de destino
- Visualización de resultados
- Comparación de viajes con buen y mal clima
- Prueba de homogeneidad de varianzas con Levene
- Prueba t para dos muestras independientes
- Interpretación estadística de resultados

## Principales resultados

- Flash Cab registró el mayor número de viajes entre las compañías analizadas.
- Loop y River North presentaron los mayores promedios de viajes finalizados.
- Los viajes realizados con malas condiciones meteorológicas tuvieron una duración promedio mayor.
- La prueba estadística mostró una diferencia significativa entre los viajes con buen y mal clima.
